# 故事概览

卡吕贝斯是一颗偏远的矿业行星，拥有丰富的[钶特](technology/cot.md)矿藏。利维坦星际公司牵头建立卡吕贝斯上唯一的殖民地[阿利贝](places/alybe.md)。各公司联合开发、共同管理。阿利贝的主要业务是钶特开采，以及邻近港口星球的货运分流。

阿利贝的人口分为公司所属人员与具有独立身份的本地居民。大停电前，公司员工及其家属约占人口三成。本地居民大多来自开发时期引入的非法劳工及其后代。1982年的罢工后，居民取得独立于公司的正式身份。详见[居民与身份](society/residents.md)。

2000年1月1日，深红发动[大停电](events/blackout.md)，切断供能与运输，夺取轨道武器。游戏开局为大停电后30日，即2000年1月31日。此时阿利贝仍处于清洗与轨道封锁之中，大部分街区停止正常生活。深红控制轨道武器和少量联网设施。她的兵力不足以占领全城。蓝袖军、唯一民主党等大型团体维持守卫、燃料、维修与运输。据点之间的道路和零散街区持续发生争夺。多数幸存者藏在建筑内，或随小队迁移，寻找愿意接纳他们的大型团体。撤离依赖小型飞船：公司雇人接走员工、追回资产；新地球联合学院出资提供物资，并雇佣佣兵撤离平民；其余居民自行筹措运输。
