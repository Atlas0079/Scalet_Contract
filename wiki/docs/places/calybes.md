# 卡吕贝斯

卡吕贝斯是一颗偏远的采矿行星，蕴藏着丰富的钶特矿藏——一种用于星际旅行的珍贵矿物。

利维坦星际公司牵头建立卡吕贝斯唯一的殖民地阿利贝，各公司联合开发、共同管理；阿利贝的主要业务是钶特开采，以及邻近港口星球的货运分流。

深红正开发一套利用活性钶特投送核弹的系统，其目标射程覆盖整个卡吕贝斯星系，包括舰队后方区域、轨道设施和航运枢纽。该系统目前仍处于研发阶段。详见[钶特](../technology/cot.md)。
