# 卡吕贝斯

卡吕贝斯是一颗偏远的矿业行星，拥有丰富的钶特矿藏。钶特是一种用于星际旅行的珍贵矿物。

利维坦星际公司牵头建立卡吕贝斯上唯一的殖民地阿利贝。各公司联合开发、共同管理。阿利贝的主要业务是钶特开采，以及邻近港口星球的货运分流。

深红正研发以活性钶特投送核弹的系统，目标射程覆盖整个卡吕贝斯星系，包括舰队后方、轨道设施和航道枢纽。该系统仍处于研发阶段。详见[钶特](../technology/cot.md)。
