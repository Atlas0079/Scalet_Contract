# 游戏：铁眼

《铁眼》是一款以小队指挥、物资搜集和撤离为核心的俯视角科幻战术射击游戏。玩家扮演作业卫星上的观察员，在阿利贝执行委托、建立据点并调查自身身份。

战局实时推进。玩家可自由暂停安排指令。直接操作的优先级高于自动交战。队伍搜集、携带物资撤离，所得用于局外整备和再次出战。

队伍由人类、机器人及仿生人组成，各有不同的技能来源和维护需求。SIA负责人类机师对远程机体的直接操控。

## 世界观背景

2000年1月1日，卡吕贝斯的殖民地阿利贝遭遇大停电。深红控制轨道武器和部分设施。大型团体控制固定据点。多数幸存者藏匿或流动。游戏开局为大停电后30日，即2000年1月31日。

观察员开局隶属中继防务，真实身份是失忆的尤里卡。剧情包括阵营委托与身份调查。
