# 游戏：铁眼

《铁眼》是一款俯视视角的科幻战术射击游戏，核心玩法围绕小队指挥、物资收集和撤离展开。玩家将扮演一艘作业卫星上的观察员，在阿利贝接取任务、建立基地，并调查自己的真实身份。

战斗以实时方式进行；玩家可随时暂停游戏以下达指令，且手动命令优先于自动交战模式。小队负责收集补给并通过撤离将其运出；所得收益将用于局外整备及下一次部署。

小队由人类、机器人和仿生人组成，它们各自拥有不同的技能来源和维护需求。SIA负责由人类机师直接操控远程机体。

## 世界背景

2000年1月1日，卡吕贝斯的殖民地阿利贝遭遇了大停电。深红掌控着轨道武器及部分设施。大型团体占据着固定的据点。大多数幸存者则躲藏起来或四处流窜。游戏故事始于大停电后30日，即2000年1月31日。

观察员最初隶属于中继防务；其真实身份是失忆的尤里卡。故事包含阵营合约和身份调查等内容。
