# 游戏：撤离循环

撤离循环包括物资收集、撤离、局外整备以及下一次部署。玩家需安排小队成员将物资运离战场，并可分批进行撤离。

## 搜索与指派

搜索可发现容器及其他来源中的补给；搜索完成后，游戏会自动暂停并打开指派界面。指派仅预留取货点——补给仍留在原地，指定搬运者必须抵达现场才能完成交接；搜索者与搬运者可以是不同的队员。

## 撤离与损失

补给品将在撤离时随实际搬运者一同进入局外仓库；战斗结束后，未被带出的装备和补给品将被视为损失，阵亡的小队成员将永久消失。合同完成与交付情况将分别记录。

部分成员可提前撤离，保留已带出的人员和收益，其余成员则继续在战场上执行任务；随后留在战场上的小队所遭受的损失，不会扣除已撤出的补给。

## 局外整备

行动结束后，小队将利用带回的资源进行整备。人员损失通过招募进行补充。各身体类型的治疗、维修及消耗品需求详见[三类作战身体](../technology/bodies.md)。
