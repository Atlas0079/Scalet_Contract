# 公司与机构

阿利贝由各公司联合开发、共同管理。当地机构涵盖矿业、航运、军工、工业设备、精密制造、仿生人、医疗与教育科研。大停电后，公司雇佣佣兵接应人员、回收资产。

| 公司与机构 | 生态位 |
| --- | --- |
| [利维坦星际公司](leviathan.md) | 矿业、殖民投资与航运 |
| [瓦尔哈拉重工](valhalla.md) | 常规军工与殖民地驻军 |
| [赫淮斯托斯星际公司](hephaestus.md) | 工业设备与现场维修 |
| [天工集团](tiangong.md) | 精密制造与工程建设 |
| [奥贡集团](ogun.md) | 新兴军工与试验装备 |
| [戈仑生命联合](golem.md) | 仿生人研发与身体整备 |
| [阿什温生命联合](ashvin.md) | 医疗、医药与生命维持耗材 |
| [新地球联合学院](new-earth-academy.md) | 教育、科研与平民援助 |

作战与接应业务见[佣兵组织](mercenaries.md)。
