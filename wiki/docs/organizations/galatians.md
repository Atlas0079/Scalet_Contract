# 加拉太人

加拉太人是一支以人类战士为主的佣兵公司，承接突袭、据点争夺战和武装护送任务；各小队围绕着拥有实战战绩的小队长组建，成员通过共同作战和瓜分战利品来提升自身地位。

该公司的总部负责承接外部合同，而各小队则自行招募成员并分配战利品。小队长在行动中会主动扩大争夺目标范围，随后以额外战利品为由向客户索要额外报酬；客户拒绝购买的回收货物将由小队转售给其他买家。

加拉太人从非真空谍报处购买设施入口和目标地点，并与中继防务争夺据点及回收物资。占领仓库后，小队通常会联合仍留在现场的守卫和运输人员共同执行下一份合同，将这个现已设防的地点直接移交给新客户。
