# 待讨论事项

以下集中记录尚未决定的制度、技术条件与剧情安排。

| 范围 | 尚待确定的内容 |
| --- | --- |
| 阿利贝尺度与运作 | 城市实际宽度、深度、人口、层数与泡的数量；不同尺度泡的功能、交通与货运能力、供能和环境维持方式。三维草模的四层与具体泡数仅作结构示意。 |
| 地表环境与穹顶 | 地表温度、气压与大气条件；巨型隔寒装置的形式，穹顶破损后的环境变化、相邻城区隔离方式，以及宇航服的具体防护条件。 |
| 共同治理 | 公共权力的分配与居民自治的权限范围。 |
| 人格与交易 | 仿生人的法律人格与离体脑组织的交易边界。 |
| 开场委托 | 观察员首批任务的委托方、目标、敌对队伍和衔接顺序。 |
| 天地人委托 | 高难度任务的具体条件、权限奖励范围及独家情报内容。 |
| 深红部队 | 她指挥机器人和仿生人的方式，机器人操控与SIA规则的关系；各地区遭到筛选、利用与袭击的具体经过。 |
| 身份调查 | 旧同事、个人记录与灾备安装记录的具体内容，线索交付次序与各阵营结局。 |
| 钶特武器 | 投送机制、精度、预警、拦截方式及首次展示威慑的事件。 |
| 撤离与整备 | 分批撤离的范围与时间条件，整备、招募和低资源恢复的具体规则。 |
| 观察员视图 | 队员与侦察设备的信息如何汇总到卫星终端，以及视野盲区、延迟和干扰的表现。 |
| 灵能（二级设定） | 风格保持克制，以传送物体、闪现、隔空操纵、感知与精神干扰为能力方向；原理、距离、目标条件、持续时间、抵抗方式及负荷后果待确认。尤里卡复苏后保留的灵能能力，以及离体脑组织施展灵能的条件待确认。 |
| 武装道士与役尸 | 审定役尸概念草案；优先明确本地指令执行与SIA的区别、可用尸体及技能来源，再确定控制距离与数量、起尸和维护成本、终止行为及装备使用。 |
