# 待讨论事项

以下列出了尚未确定的机构设置、技术条件及剧情安排。

| 范围 | 待定事项 |
| --- | --- |
| 共同治理 | 确认共同治理与法律草案中的协议、公共机构及防务权限；确定学院是否参与联合管理。 |
| 法人资格与贸易 | 仿生人的法人资格、拒绝召回后的权利，以及无实体脑组织贸易的边界。 |
| 居民自治 | 1982年罢工的参与者及经过，以及灾后自治机构保留的职权。 |
| 开局委托 | 观察员首批任务的委托方、目标、敌对团队及任务顺序。 |
| 公司与居民 | 哪些股票借贷、设备提取、仿生人召回及人员回收会转化为实际任务，以及各方如何对交付结果作出反应。 |
| 幸存者团体 | 蓝袖军、阿利贝唯一民主党、隐名者及黑栈等据点的名称、地图边界及其具体任务。 |
| 天地人任务 | 高难度任务的具体条件、通关奖励的范围以及独家情报的内容。 |
| 驻军 | 瓦尔哈拉总部是否下达撤离命令，以及驻军如何执行该命令。 |
| 深红麾下部队 | 她如何指挥机器人和仿生人，以及机器人控制与SIA规则之间的关系；各区域遭受的筛选、渗透和攻击的具体经过。 |
| 身份调查 | 前同事的具体信息、个人档案及灾后恢复设施记录，线索交付的顺序，以及各派系的结局。 |
| 钶特武器 | 交付机制、精度、预警与拦截，以及首次彰显其威慑力的事件。 |
| 撤离与装备 | 分阶段撤离的范围与时机，以及装备配置、招募和低资源恢复的具体规则。 |
| 观察员访问权限 | 确认视图与接入方案；确定直接接入的条件、疼痛、疲劳、灵能负荷以及与机师的合作模式，并分析盲区、延迟和干扰对战术视图的影响。 |
