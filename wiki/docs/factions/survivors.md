# 幸存者团体

大停电后，多数幸存者藏匿或在城区间迁移，寻找物资与庇护。大型团体能够维持固定据点、守卫和供给，在道路与设施周围争夺控制权。

| 团体 | 生态位 |
| --- | --- |
| [蓝袖军](blue-sleeves.md) | 残余驻军与军事秩序 |
| [阿利贝唯一民主党](sole-democratic-party.md) | 本地劳工的政治组织 |
| [隐名者](the-untold.md) | 围绕深红形成的秘密信仰团体 |
| [黑栈](black-stack.md) | 地下流通与武装掠夺 |

零散强盗也在城区抢夺和转卖物资。公司人员向所属公司寻求接应，本地居民依靠外部援助或自行筹措运输。
