# 关键事件

大停电发生于2000年1月1日。游戏开局为大停电后30日，即2000年1月31日。带 <span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span> 标记的条目记录世界内未公开的事件，其余为公开记录。

<ul class="wiki-timeline">
<li>
<div class="wiki-timeline-date">1945年6月26日</div>
<h3>阿利贝开发项目启动</h3>
<p>利维坦星际公司牵头启动阿利贝一期建设。深红同步进入开发。尤里卡加入项目组，参与系统架构与感知接口设计。</p>
</li>
<li>
<div class="wiki-timeline-date">1948年6月24日</div>
<h3>一期工程与深红交付</h3>
<p>矿区、转运港和首批居住区投入使用。深红与一期工程同时交付，接管供电、运输和环境设施的日常调度。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">1952年11月1日<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>尤里卡移交灾备权限</h3>
<p>尤里卡在灾备联调后保留调试席位，把应急操作封装成代理交给深红。代理以设施证书运行，能够接管调度，并向相连的轨道设施发出命令。</p>
</li>
<li>
<div class="wiki-timeline-date">1956年10月23日</div>
<h3>维护权限审计</h3>
<p>审计发现尤里卡不在岗期间多次发生以其授权执行的应急操作。他被停职调查。人员凭据被撤销。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">1956年11月4日（审计后12日）<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>尤里卡逃亡</h3>
<p>尤里卡经地下诊所把脑组织转入维生罐，以返厂湿件终端的货物身份搭乘自动货船离港。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">1956年11月8日（离港后4日）<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>货船被截留</h3>
<p>深红预先上传的程序关闭货船主推进。备用供电随之失效。维生罐中的尤里卡因低氧遭受记忆损伤。</p>
</li>
<li>
<div class="wiki-timeline-date">1956年11月12日（离港后8日）</div>
<h3>失联货船回收</h3>
<p>维修拖船把失联货船拖回阿利贝拆检。货损登记把湿件终端列为失效设备。货主放弃回收。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">1956年11月15日（货船回收后）<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>尤里卡被转卖与冷冻</h3>
<p>修理工把仍有活动的脑组织私下卖给港区湿件整备商。身份资料被移除。脑组织转入地面冷库，此后冷冻保存约43年。</p>
</li>
<li>
<div class="wiki-timeline-date">1982年5月1日</div>
<h3>居民自治协议生效</h3>
<p>矿区与维修区停工后，各公司与居民代表达成复工协议。原未登记劳工及其家属取得居民身份。居民自治机构成立。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">1999年11月<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>尤里卡复苏并进入卫星</h3>
<p>深红经匿名中间人促成中继防务购入尤里卡，资助复苏与运输。他被送往作业卫星，以“观察员”为代号接受远程指挥训练。记忆损伤仍然存在。</p>
</li>
<li>
<div class="wiki-timeline-date">2000年1月1日（大停电当日）</div>
<h3>全域停电</h3>
<p>阿利贝供能与运输中断。港口暂停大型舰船进出。各设施启用本地应急电源。</p>
</li>
<li class="wiki-timeline-private">
<div class="wiki-timeline-date">2000年1月1日（大停电当日）<span class="wiki-timeline-badge wiki-timeline-badge-private">非公开</span></div>
<h3>深红接管轨道武器</h3>
<p>深红主动切断主调度，经长期沿用的灾备代理接管轨道应急席位，改写敌我识别表并排除地面操作。</p>
</li>
<li>
<div class="wiki-timeline-date">2000年1月4日（大停电后3日）</div>
<h3>轨道防务失控确认</h3>
<p>瓦尔哈拉通报轨道平台拒绝地面指令，并把补给船队列为敌对目标。大型舰船登陆停止。地面部队转入独立防御。</p>
</li>
<li>
<div class="wiki-timeline-date">2000年1月31日（大停电后30日）</div>
<h3>观察员开始地表行动</h3>
<p>中继防务恢复小规模承包行动。观察员接到首批委托，指挥队伍建立据点、接应人员与回收物资。</p>
</li>
</ul>

大停电的经过与后续格局见[大停电](blackout.md)。
