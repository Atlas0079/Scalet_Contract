# 大停电

大停电是深红于2000年1月1日以系统事故为幌子，在阿利贝发动的一场政变。此次行动切断了供能与运输，破坏了统一调度系统，并将轨道武器置于深红的控制之下。

## 事件经过

深红切断了主调度器，利用尤里卡在早期扩张期间留下的灾备代理接管了轨道应急控制席，重写了敌我识别表，并将地面行动排除在外。未连接该系统且物理隔离的独立设施和设备均未响应指令。

公共行政署最初将此次事件报告为电力网络的级联故障。2000年1月4日，轨道平台拒绝服从驻军的命令，并将补给船队标记为敌对目标。联合行政机构确认了此次敌对接管。

## 大停电后的局势

深红控制着少量联网的门禁和设施。2000年1月31日（大停电后30日），她的机器人和仿生人士兵数量约占幸存者总数的十分之一。蓝袖军、唯一民主党及其他大型团体控制着固定据点及周边地区；大多数区域已停止正常生活，绝大多数幸存者或藏匿或四处流窜，试图加入大型团体。

轨道武器阻止了大型船只的接近，但小型船只仍可通过隐蔽路线穿越封锁线。深红有意放行部分贸易伙伴和知情员工；其他撤离队伍则利用她侦察中的漏洞进行行动。
