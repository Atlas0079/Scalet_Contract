# 当前射击机制与数值清单

更新日期：2026-09-30。本文描述当前多维射击、一次过补偿与停火重新瞄准实现；替代 9 月 29 日的旧数值审计。规范依据为 LOCAL_CHARACTER_ARCHITECTURE.md 第 13、16 节。

## 1. 一发子弹如何产生

1. SCAbilityRules.evaluate 解析身体、意识、芯片、技能及来源，按种族转换为统一能力。
2. 最终通用力量、精细执行、感知及响应先接受来源修正，再由 _shooting_capabilities 派生射击输出；各射击输出随后接受自己的来源修正一次。
3. 射击层只消费能力快照，不读取种族属性、技能 XP 或按种族分支。
4. 每发先读取可见持枪姿态与机械散布并生成子弹，再向角速度施加后坐冲量。本发不受自身后坐影响。
5. 测试场从骨骼约束后的实际三维枪口发射；持枪偏移驱动手臂与枪，机械散布独立叠加。
6. 停火结束本段后坐，把当前可见角度交给重新瞄准；没有停火被动回正或补偿记忆衰减。

实际射向由目标方向、连续持枪漂移、后坐或重新瞄准偏移、骨骼限制及机械散布共同决定，不是命中概率相乘。

## 2. 枪械、配件与弹药

角度对为 [水平,垂直]；散布数值是单侧硬边界半宽。

| 参数 | 试验卡宾枪 | 普通步枪 |
| --- | --- | --- |
| 射击间隔 | 0.1 s，600 发/分 | 0.25 s，240 发/分 |
| 枪械散布半宽 | [0.45°,0.40°] | 相同 |
| 弹药散布半宽 | [0.15°,0.15°] | 相同 |
| 后坐角速度冲量 | [3.6,13] °/s | 相同 |
| 后坐角度界限 | [12°,18°] | 相同 |
| 连射支撑频率 support_frequency | 4 /s | 相同 |
| 弹速 | 300 m/s | 相同 |
| 实际三维射程 | 16 m | 18 m |
| 弹匣 / 基础换弹时间 | 30 / 2.5 s | 相同 |
| 枪重 | 3.2 kg | 3.8 kg |
| 弹丸质量 / 伤害 | 0.012 kg / 35 | 相同 |

枪重、弹重仍未用于后坐计算；没有子弹重力下坠、风偏、空气阻力、穿透或跳弹。本轮不扩大这些模型。
每轴机械散布为 (U1-U2)×半宽，中心密、边缘稀。枪械与弹药独立抽样。默认无配件；精密枪管 [0.7,0.7] 仅乘枪械散布。

## 3. 多维角色函数

统一输入：B=最终 force_n/基准 force_n，H=最终 manipulation_rate，O=最终 identification_rate，R=最终 response_delay_seconds，C_eff=统一控制有效性，T=有效射击等级/等级上限（当前 20）。
R 已含 SIA 延迟，射击补偿不得再加一次。自主与远程控制的技能渠道由 SCSkills.compose 先完成，射击层看不到机师或芯片。

| 通用输出 | 当前默认函数 |
| --- | --- |
| 冲量倍率 | clamp(0.85/(sqrt(B)×(0.7+0.3T)),0.25,4) |
| 开始补偿延迟 | R+0.12/(sqrt(O)×(0.4+1.2T)) s |
| 补偿建立时间常数 | 0.35/(sqrt(H)×(0.7+0.6T)) s |
| 补偿加速度上限 | 180×B×C_eff °/s²，训练不增加上限 |
| 连射支撑倍率 | sqrt(B) |
| 纠正频率 | 8×sqrt(H)×(0.75+0.5T) /s |
| 后坐预估比例 | 0.2+0.8T |
| 一次过补偿目标幅度 | min(6,4×max(0,B-1)×(1-T)²) ° |
| 瞄准进度增长 | 1.25×sqrt(H×O)×(0.7+0.6T) /s |
| 未稳定持枪半宽 | [6,5]/(sqrt(H)×(0.8+0.4T)) ° |
| 稳定持枪半宽 | [0.2,0.2]/(sqrt(H)×(0.6+0.8T)) ° |

力量、精细执行、感知或有效控制为零时关闭动作；误差返回上限、主动速度为零，不用极小数补出动作。最终误差限制 [0,45]，稳定误差不超过未稳定误差。
换弹、医疗等操作仍使用既有独立公式。本轮没有把新的射击训练权重应用到其他操作。

## 4. 瞄准进度与重新瞄准

瞄准进度 A∈[0,1]；误差半宽为 settled+(unsettled-settled)×(1-A)²。
移动按 0.9/m、大幅转向按 0.008/° 扣减；未跟踪目标按 0.5/s 衰减；切换目标保留 35% 进度。
正式 AI 使用 minimum_fire_progress=0.55；测试场允许手动未充分瞄准就开火。
持枪漂移在不规则随机锚点之间平滑变化，间隔基准 0.65 s；不是正弦摆动。

停火调用 stop_firing，将 θ+剩余重新瞄准偏移转交给 reaim_offset_degrees，清零角速度、补偿、连射时间与过补偿状态。
重新瞄准按 aim_gain_per_second×90°/进度的角速度移向零；只在跟踪目标且能瞄准时推进，有限时间完成、没有弹簧长尾。
瞄准进度和角度对准是不同状态：保留持枪稳定程度不代表枪口已对准。再次提前开火，首发仍使用当前位置，后坐继承尚未消除的重新瞄准偏移。
暂停不推进这些状态。无目标时保留偏移，重新获得目标后对准当前目标；不是返回一个旧目标点。

## 5. 连射控制与一次过补偿

每发纵向冲量固定、横向冲量随机，再乘角色冲量倍率。先发射、后增加角速度。
经过反应延迟后，补偿建立程度 α 以时间常数指数趋近 1；α 是动作建立比例，不是命中率或误差消除比例。
纠正请求为 -f²(θ-目标偏移)-2fω-预估比例×预期单发冲量/射击间隔。
整项限幅到 ±身体控制上限，再乘当前用力比例。预估和过补偿都不能绕过上限。

一次过补偿阶段：
1. 本段首次开始补偿时，若目标幅度大于零，进入 push；否则直接 done。
2. push 的目标向下，最长 0.65 s。用力比例为 min(1,α×(1+幅度×0.5/°))，表达纠正开始时用力过猛。
3. 进入 return 后目标回到零、恢复普通 α。枪口返回零点后进入 done，关闭本段再次下穿目标。
4. 下移目标经过相同动力学与力度上限，不是弹道附加角。实际下压幅度不等于目标幅度，也不保证一定能达到。
5. 只有结束本段连射后才重新允许发生，不靠低阻尼产生上下振荡。

连射中身体支撑使用武器 support_frequency×recoil_support_scale；停火后不运行该模型。
显式松扳机、换弹、交战目标丢失、友军挡线、移动接管等立即停火。没有显式扳机事件的调用方，以 max(0.35 s,1.5×射击间隔) 作安全超时判定。
积分子步不超过 1/480 s，发射时刻切分；角度限幅后清除向外角速度。

## 6. 当前交叉验证样例

下表为四秒持续射击的后坐状态，不含漂移、机械散布或骨骼限制。力量条件通过最终 force_n 来源修正，其他能力保持健康基准。默认卡宾枪纵向冲量 13 °/s。

| 角色 | B / 技能 | 反应延迟 | 最大控制上限 | 后段偏移均值 |
| --- | --- | --- | --- | --- |
| 弱力量高手 | 0.3 / 20 | 0.325 s | 54 °/s² | 约 +17.69°，压不住 |
| 强力量新手 | 2 / 0 | 0.55 s | 360 °/s² | 约 +1.23° |
| 标准力量新手 | 1 / 0 | 0.55 s | 180 °/s² | 约 +2.43° |
| 标准力量高手 | 1 / 20 | 0.325 s | 180 °/s² | 约 +0.05° |

强力量新手最低约 -0.19°，下穿目标一次；其余组合没有额外向下过补偿。
弱力量高手改用纵向冲量 3 °/s 的测试输入后，后段偏移约 +0.12°。该输入用于验证适配关系，不宣称已有新武器型号。

测试场 K 切换技能 0/10/20，J 切换当前身体力量的标准/强/弱（1/2/0.3）条件；均清空本次试射。J 使用现有通用力量来源，不修改种族固有值或经验。F2 显示能力与来源。

## 7. 视觉与弹道边界

位置后冲仍由 presentation.json 独立配置：每发位移 0.009 m、速度冲量 3.7 m/s、侧向冲量 0.38 m/s、上限 0.065/0.009 m、恢复频率 42/s。
这组视觉参数本轮未重调；侧向输入归一化后仍不会随角色机械后坐等比例缩放。它不能与后坐角或停火重新瞄准混称“回正”。

测试场由实际受约束的骨骼枪口发射，水平、俯仰与抛壳口跟随姿态；正式战场仍采用角色中心加枪口高度的概念枪口。
两者共用能力、后坐、停火重新瞄准与机械散布，但测试场的骨骼表现不是正式战场已经接入 3D 枪口的证据。
子弹沿初始三维方向直线飞行，检测目标、掩体和地面。正面弹着图来自真实弹丸，不另抽样误差；被提前截停的子弹不画虚构弹孔。
测试场重置种子 71093；相同条件可重现，清空靶图不重置随机序列，但释放扳机并按新规则进入重新瞄准。
