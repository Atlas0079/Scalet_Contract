# 当前射击机制与数值清单

审计日期：2026-09-29。依据当前源码与只读数值采样；本文描述已实现行为，不是未来设计。未修改任何生产代码或配置。默认对象：测试场、人类、试验卡宾枪、射击技能 10、健康无压力、无配件、无额外属性来源。

## 1. 一发子弹如何产生

1. 根据种族属性、身体状态、控制者状态、技能与来源加成，计算角色能力。
2. 随时间更新瞄准进度 A、持枪漂移、后坐角度和角速度。
3. 扣扳机时先保存当前持枪误差和目标，再独立抽样枪械与弹药散布。
4. 本发采样后，才把本发后坐冲量加入角速度，影响后续枪口与下一发。
5. 测试场由骨骼约束解算实际枪口姿态；子弹从真实枪口沿枪管方向叠加机械散布飞出。偏离并非全部表现成枪口与子弹之间的夹角。
6. 按初始三维方向直线飞行，以连续线段检测靶体、掩体和地面；最早碰撞结束飞行。

概念关系：实际射向 = 受姿态约束的（目标方向 + 连续持枪漂移 + 累计后坐角度）+ 枪械随机散布 + 弹药随机散布。不是四个命中率相乘。

## 2. 枪械、配件、弹药

角度对均为【水平，垂直】；精度数值是单侧最大角度，不是总直径或标准差。

| 因子 | 试验卡宾枪 | 普通步枪 | 生效位置 |
|---|---:|---:|---|
| 射击间隔 | 0.1 s（600 发/分） | 0.25 s（240 发/分） | 冲量累积频率与控制预测 |
| 枪械散布半宽 | [0.45°,0.40°] | 相同 | 每发独立三角分布 |
| 弹药散布半宽 | [0.15°,0.15°] | 相同 | 与枪械散布独立相加 |
| 当前配件 | 无 | 无 | 精密枪管定义存在但未装备 |
| 精密枪管倍率 | [0.7,0.7] | 相同 | 仅乘枪械精度，不乘弹药或持枪误差 |
| 后坐角速度冲量 | [3.6,13] °/s | 相同 | 再乘角色 recoil_kick_scale |
| 后坐角度硬上限 | [12°,18°] | 相同 | 正负两侧限幅，向外角速度归零 |
| 被动回正系数 | 4 s⁻¹ | 相同 | 再乘角色恢复倍率，最低倍率 0.25 |
| 子弹速度 | 300 m/s | 相同 | 弹药速度 × 枪口速度倍率 1 |
| 最大实际飞行路程 | 16 m | 18 m | 三维路程，非水平距离 |
| 弹匣 / 基础换弹时间 | 30 / 2.5 s | 相同 | 测试场不消耗弹药；正式战斗消耗 |
| 弹药伤害 | 35 | 相同 | 碰撞后伤害，不改变初始射向 |
| 枪械质量 | 3.2 kg | 3.8 kg | 未用于后坐计算 |
| 弹丸质量 | 0.012 kg | 相同 | 未用于后坐或弹道下坠计算 |

每轴三角散布 = (随机数 U1 - 随机数 U2) × 半宽，U∈[0,1]；中心密、边缘稀。枪械与弹药半宽上界相加为 [0.60°,0.55°]。这两个量并不是每次都取最大值。

当前无风偏、重力下坠、空气阻力、穿透、跳弹、枪管温度与磨损修正；高度由起点和固定仰角决定。伤害并不反推后坐冲量。

## 3. 瞄准进度、持枪漂移

A 范围 [0,1]。具备瞄准权限且正在跟踪时：

`dA/dt = 瞄准增长率 - 0.9×实际移速(m/s) - 0.008×目标方位变化速度(°/s)`

不跟踪时，把增长率替换为 -0.5。最终 A 限制在 [0,1]。换目标/切换高度相关流程乘保留率 0.35；换射位重置为 0。测试场鼠标连续改变目标主要通过方位变化速度扣除 A。

`持枪误差半宽 = 稳定半宽 + (未稳定半宽 - 稳定半宽) × (1-A)^2`

默认技能 10：增长率 1.25/s，从 0 到 1 需 0.8 s；未稳定 [6°,5°]，充分瞄准 [0.2°,0.2°]。A=0.5 时为 [1.65°,1.40°]。全速 2 m/s 时，净增长为 1.25-1.8=-0.55/s，因此会逐渐丢失瞄准进度。持续开火本身不直接扣 A，失准由后坐状态单独承担。

漂移不是每发重新抽样：它在确定性随机锚点间平滑插值，水平锚点间隔 0.65 s，垂直时间速率为水平的 0.79（间隔约 0.823 s）。漂移乘当前持枪半宽，再加当前后坐角度。相邻子弹因此相关。它没有正弦周期，但平滑过渡仍可能看起来缓慢摇摆。

默认满瞄、无后坐的保守总半宽为 [0.8°,0.75°]；按枪口到观察面水平距离 10 m、近水平射击估算，约 ±14.0 cm / ±13.1 cm。这还未计姿态残差和枪口位移包络，是上界估算而非通常弹群大小。

## 4. 属性与技能如何进入射击

定义归一化参数：

| 中间量 | 人类 | 机器人 | 仿生人 |
|---|---|---|---|
| 力量 p | 肌力/100 | 执行器出力/100 | 肌纤维出力/100 |
| 精细控制 d | 协调/100 | 伺服精度/100 | 精细控制/100 |
| 身体效率 u | 1-0.5×疲劳 | clamp(能量/0.1,0,1)×(1-0.7×clamp(热量/max(0.1,冷却/100),0,1))×(1-电子故障) | 人造血×(1-0.5×代谢负担)×(1-循环故障) |

F 为 manipulation 身体功能：按身体配置，对相关区域的当前/最大生命值比率加权平均。部件提供的基础属性与奖励也经属性来源系统进入 p、d 等。

控制者状态 `c = clamp(1-0.4×压力/max(0.1,意志/100)-0.4×疼痛,0,1)`。

自主控制 q=1。SIA 时 `q=(0.5+0.025×SIA技能)×链路质量×当前同步率`。同步率由基础值与来源加成计算后限制到该机师—机体的同步上限。链路延迟加入正式战斗的反应时间，目前不模拟枪口输入延迟。

射击技能 S∈[0,20]；经验等级 `min(20,sqrt(XP/100))`。自主角色用自身意识技能；机器人工作技能=机师30%+芯片70%；SIA 仿生人=机师70%+自身意识原始等级30%，再按规则施加来源加成。SIA操控技能本身使用机师技能，不走工作技能混合。

`k=0.5+0.05×S`

`精度能力 P=d×u×F×c×q×k`

`持枪控制能力 G=sqrt(p×u×F)×c×q×k`

| 派生能力 | 原始计算 |
|---|---|
| 瞄准增长率 | 1.25×P |
| 未稳定半宽 | [6,5]/P |
| 满瞄半宽 | [0.2,0.2]/P |
| 后坐冲量倍率 | 1/G，最后限制 [0.25,4] |
| 开始主动补偿延迟 | 0.25/max(0.1,P) 秒，最低 0.01 |
| 补偿建立时间常数 | 0.35/max(0.1,P) 秒，最低 0.01 |
| 最大主动补偿角加速度 | 180×G °/s² |
| 被动恢复倍率 | P，最后限制 [0,4] |
| 换弹速度倍率 | P |

P=0 时持枪半宽退化为 [45°,45°]，瞄准权限也会关闭；G=0 时冲量倍率取4。向量半宽限制到0～45°，稳定半宽不超过未稳定半宽。

来源可作用于基础属性、技能和最终能力。一般修正公式：`max(0,基础+加值)×max(0,1+百分比之和)×独立倍率之积`；过期、未激活、卸下部件、失效部件与互斥叠加规则先过滤。来源归属仍区分身体、控制者、芯片；部件损坏可缩放奖励。当前默认测试员 sources 为空，不能把尚未配置的药剂/装备加成算作正在生效。

其他间接因子：耐力/驱动效率/神经速度影响移速，从而影响瞄准损失；视力功能影响能否瞄准，感官数值主要影响探测而非直接缩小散布。死亡、震撼、控制意识不可用、SIA断链、同步或链路质量为0会关闭权限。

## 5. 连射后坐：冲量、回正、补偿

状态为后坐角度 θ、角速度 ω、补偿程度 b、连射持续时间、距上发时间。

- 每发在旧状态采样后施加 `ω += [均匀随机(-3.6,+3.6), 固定13] × 冲量倍率`。纵向冲量当前没有每发随机幅度。
- 连射判定窗口为 `max(0.35 s,射击间隔×1.5)`：卡宾枪0.35 s，普通步枪0.375 s。此窗口内连射年龄增长，即使刚松开扳机。
- 达到响应延迟后，b 以建立时间常数趋近1。达到一个时间常数只是约63.2%，不是瞬间满补偿。
- 断连射后，b 按0.6 s时间常数衰减；短点射之间会保留控制记忆。
- 主动回正系数 f=8 s⁻¹。控制器请求 `a=-f²θ-2fω-预期冲量/射击间隔`，每轴先限制在 ±最大角加速度，再乘 b。
- 预期冲量只有纵向，且只在距上发时间小于一发间隔时生效。这是按枪械射速预测后坐的控制项，不是第二份随机散布。
- 被动回正系数 `λ=4×max(0.25,恢复倍率)`；临界阻尼解析积分主动加速度与被动回正，并限制角度。
- 主动控制用不超过1/480 s子步积分；开火时刻切分更新。显示帧率不用于生成周期摆动。

| 满瞄时间 | 1.6 s | 0.8 s | 0.533 s |
| 满瞄持枪半宽 | ±0.4° | ±0.2° | ±0.133° |
| 横向冲量范围 | ±7.2 °/s | ±3.6 °/s | ±2.4 °/s |
| 纵向冲量 | 26 °/s | 13 °/s | 8.667 °/s |

## 6. 姿态、视觉力度与弹道边界

配置 presentation.json 中另有一组可见的后冲位移参数：

| 参数 | 当前值 |
|---|---:|
| 恢复系数 frequency | 42 s⁻¹ |
| 每发立即向后位移 | 0.009 m |
| 向后速度冲量 | 3.7 m/s |
| 侧向速度冲量幅度 | 0.38 m/s |
| 最大向后位移 | 0.065 m |
| 最大侧向位移 | 0.009 m |
| 腰部旋转限制 | 35° |
| 手部瞄准修正限制 | 18° |
| 枪口俯仰限制 | 35° |

侧向视觉冲量由本发实际横向冲量/其上限得到，不额外随机。它使用归一化值，因此技能改变机械冲量强度，不会等比例改变这组后冲位移幅度。上身位移为 [侧向位移×0.5,0,-后向位移]；枪随持枪骨骼移动。该组参数不额外添加一个弹道散布角，但实际枪口位置和姿态解算会随之变化。

角色手臂长度与双手握持约束还可能限制极端枪口角度。测试场子弹使用同一受约束枪姿，不是理想瞄准方向。因此极端情况下不能只把所有角度简单相加。

在40 px/m比例下，立即后退0.009 m只有0.36 px，最大后退0.065 m为2.6 px。上身侧移上限0.0045 m为0.18 px。俯仰主要表现为俯视枪管投影长度变化，不能像左右旋转那样明显。这些是“数值后坐明显，视觉却软”的候选原因，不是已经由玩家实验确认的结论。

曳光线长2 m、亮度0.9、消退0.045 s，每发可见；枪口火光寿命0.075 s、长度0.25 m、宽0.073 m；这些不改变碰撞或精度。弹壳重力10 m/s²只作用于弹壳，不是子弹重力。

目标距离将角误差放大为线性误差；目标高度、半径、掩体位置/高度和地面决定能否命中。测试靶半径0.23 m、高1.8 m，瞄准高度1.25/0.65/1.65 m。测试场靶图的距离从枪口算起，因此与人物中心标示的射位距离不同。

准星是围绕期望瞄准点计算的保守范围：瞄准误差+枪械精度+弹药精度+后坐角度绝对值，并包含旋转造成的枪口位置变化。它不产生新的散布，不以当前随机漂移点作为靶心。

## 7. 测试场与正式战斗的差异

| 项目 | 测试场 | 正式战斗 |
|---|---|---|
| 出膛位置 | 骨骼解算后的真实枪口，防穿墙裁切 | 角色中心平面坐标+配置枪口高度 |
| 姿态对发射方向的约束 | 有 | 不经过测试场骨骼解算 |
| 弹药/经验 | 不耗弹、不成长 | 耗弹，每发奖励射击经验 |
| 最低瞄准后开火 | 可直接试射 | A≥0.55 |
| 额外开火门槛 | 未暂停、未换弹、冷却完、可瞄准 | 还检查站立、朝向误差≤5°、反应时间、射程、视线/友军挡线等 |
| 目标 | 静止圆柱靶与固定掩体 | 角色移动轨迹、身体高度与地形 |

正式战斗反应时间来自基础0.25/max(0.1,d×c×q)，SIA再加链路延迟，可受来源加成。正式战斗还通过感知、交战逻辑影响何时选中目标，命中后通过身体部位和防护结算伤害；这些不应混作枪械散布。

测试场重置把弹道随机种子设为71093，瞄准时钟归零；相同操作条件可复现同一序列。漂移由角色ID与瞄准时钟决定。这会产生“重来还是一样”的观感，并非没有随机抽样。清空靶纸仅清记录，不重置该序列或后坐状态。

## 8. 优先讨论的数值问题

1. 先确定“无技能也能最终压回，还是可能一直压不住”。当前技能0的能力组合属于后者。
2. 技能同时影响六类以上因素，0/10/20不是小幅差别。应先定义三档预期弹着曲线，再决定各项权重。
3. 垂直冲量固定，横向冲量随机；不能把每发轨迹的纵向规律当作没有随机机制。
4. 区分角度后坐和可见位移：前者影响下一发，后者影响力量感。测试场顶视比例下部分位移不足1像素。
5. 固定随机种子适合数值对比。需要考察自然观感时，再增加可控换种子入口；当前尚未新增。
