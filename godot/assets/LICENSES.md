# Bundled assets

- `NotoSansSC-Regular.ttf`: Noto Sans SC, weight 400 instantiated from the Google Fonts variable font. SIL Open Font License 1.1; see `OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/notosanssc . Copied from this project's existing assets.
- The ten `.wav` files are the project's original deterministic synthesized sounds, generated by `combat_demo/tools/make_assets.py`. No sampled recordings or external sound packs are used.
- The tactical study in `presentation/tactical` uses `characters/rifle_mannequin.glb`: a Quaternius humanoid/rig (CC0; see `characters/animations-LICENSE.txt`) with retargeted Kevin Iglesias free rifle animations and rifle mesh (see `characters/rifle-source-license.pdf`). Original source archives and conversion tooling are retained locally in `.art-preview-local`. The flat character shell, gait, recoil and firing effects are project code.

## CRT shader reference

`presentation/maintenance/crt.gdshader` adapts **Realistic CRT shader** by **c64cosmin**, published as CC0 at https://godotshaders.com/shader/realistic-crt-shader/ . The original credits c64cosmin for the grille and integration, pend00 for warp/vignette, Timothy Lottes for scanlines and AHOPNESS for the port. This project adapts viewport texture input, luminance calibration, strength controls, curve-aware mouse mapping and low-amplitude noise/interference/rolling-line effects. The reference page’s images and other depicted assets are not incorporated.

## CRT cabin experiment

`environment/television_02/`: **Television 02**, by **Benny Weimer**, from https://polyhaven.com/a/television_02 . CC0: https://polyhaven.com/license . The downloaded 2K glTF, geometry buffer and textures are unchanged and checked against the source API MD5 values. `television_live.gltf` and `screen_surfaces.bin` split the existing connected glass surface into its own material slot, preserving all 2,310 triangles and original vertex attributes (512 glass triangles). No replacement display housing or glass geometry is generated. The project supplies live SubViewport material, input routing, camera transitions and simple cabin structure. The desk reuses the existing Poly Haven painted wooden table listed above. This is a CRT television used as a monitor prototype; it is not an original project-authored hardware model.


## Seated cabin desk study

`environment/security_camera_01/`: **Security Camera 01**, by **Alexander Otterbeck** (modeling/texturing) and **Yann Kervran** (rigging), https://polyhaven.com/a/security_camera_01 . CC0, https://polyhaven.com/license . The 1K glTF, buffer and included textures were downloaded using Poly Haven file metadata and verified against each source MD5. They are bundled locally.

`environment/boombox/`: **Boombox**, by **Thomas Paul Mouilleron**, https://polyhaven.com/a/boombox . CC0, https://polyhaven.com/license . The downloaded 1K glTF, geometry buffer and textures were checked against source MD5 values and retained. `boombox_interactive.glb` separates connected authored mesh components and recentres the source volume knob's pivot for interaction; UV seams are welded during conversion and textures embedded. The knob is part of the source model, not replacement project geometry. The downloaded model is retained but is not instantiated in the current cabin; audio-prop and volume-knob interaction have been removed.

`environment/alarm_clock_1980s/alarm_clock.glb`: **Alarm Clock (Late 1980s)**, by **zawhatthe**, https://blendswap.com/blend/27527 . The source page declares CC0. The user supplied the downloaded `.blend`; the original remains unchanged in their Downloads directory. The runtime GLB evaluates source modifiers, converts authored text to mesh, separates authored button islands, removes the Blender camera, and replaces unsupported display shaders. The existing display plane receives normalized UVs for a live clock texture; its housing, display glass and physical buttons retain source geometry. SLEEP, ALARM, FAST and SLOW bind to the original buttons.

The three screens stand on the desktop and do not move. The project supplies seated camera focus/framing, a higher lean for the clock on the centre CRT, live-picture-driven screen illumination, weak live clock digits and a front-panel indicator attached to the security camera. No mechanical support animation or temporary alarm/audio housing is used.
