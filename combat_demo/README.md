# 铁眼

当前运行入口是 Godot 舱室主场景。根目录 `Start Demo.cmd`、`Start Godot.cmd` 默认进入舱室；`Open CRT Cabin.command` / `.cmd` 直接打开同一场景，使用 Forward+。`Open Tactical Preview.cmd` 保留角色与射击测试场景的独立开发入口；`Open Godot Editor.cmd` 用于打开工程。场景名称与架构职责统一见 [战术玩法与表现设计第 16 节](docs/demo_design.md#16-项目职责与实现边界)。


本目录保存玩法设计、验证资料及字体与音效制作工具。游戏运行、模拟逻辑和后续开发统一使用 `godot/`；当前尚未完成按最新美学搭建的正式战场。

## 当前设计

硬核俯视角战术射击采用多角色指挥、实时推进与自由战术暂停。美术采用方案 A：三维制作干净矢量画感底图，文字采用中文像素字体，干净场景直接进入 CRT，文字保留清晰独立合成，由其内部采样形成像素感。项目输出为 2560×1440，舱室中央主屏的 CRT 场景信号为 864×540，左侧 CRT 为 720×540，物体与门按一米格组织，场景保持严格正交纯顶视、丰富光影与叙事性布局。具体要求见 [美学方向](../docs/art-direction.md)。

## 当前测试场景与指挥 UI

从默认舱室入口聚焦中央 CRT，黑底页面只显示“启动测试场景”按钮。点击进入独立的 500×500 米机修物流片区：车间、转运仓库、运输通路及整备房间；四名初始队员从入口集结，另有 24 名敌人与 42 名中立人员，进入时暂停。

顶部集中时间、暂停、速度和常用指挥；底部四张队员卡显示行动、伤情、弹药与已安装队列数，右侧详情默认收起。左键单选／框选、Shift 增减选择或追加命令、1–4 选择队员、Ctrl+A 全选；右键地面松开提交移动，拖动指定朝向；Q 选择警戒位置及方向，R 换弹，X 停止，E 操作近处已知门，F10 查看本地性能，空格暂停／继续，Tab 切换 0.5／1 倍速。WASD／中键平移地图，滚轮／触控板捏合以指针位置平滑缩放，触控板双指平移；顶部 −／＋、键盘 ±、Home／全图、定位、近看可直接调整视图，米数显示可见地图纵向范围。全图小队计数标记可单击选择、双击近看。Esc 先取消正在编辑的操作，再返回舱室；局内 F1／F2 为编组，返回观察后才使用舱室的设备快捷键。

场景与 UI 位于 `godot/presentation/field/`，直接消费 SCWorld／SCPlanner，保留独立场景层和清晰文字层。共用 CRT、物体描边和表面材质位于 `godot/presentation/rendering/`。原维护站场景、专用适配和独立启动器已移除，仍在使用的模型保留。

这版提供基础小队指挥、三态迷雾与已知路线、敌对阵营交火和远近模拟；物资分配、撤离和局外结算继续按已确认的玩法设计接入。整体美术与操作体验待用户验看。
