# Scarlet Contract / 灰港档案室

当前版本 **1.7.4：重叠减速延时**。先选队员，右键门，在右栏依次选择行动及“立即下令”或“编排站位”。也可点击地图左上“房间操作”后选择区域，或使用 Ctrl＋右键房间。

- **立即下令**：采用默认站位；闪光突入先选择合法落点。运行中立即执行，暂停中按空格执行。
- **编排站位**：自动暂停并聚焦入口。右栏切换“门外准备／进门就位／闪光落点”；四名队员和提交区始终可见。点击地图队员、队员卡或数字 1–4 只切换编辑对象，普通空地点击不会丢草稿。
- **编辑**：左键选队员或当前阶段的编号标记，右键在地图上设置其站位；右键按住拖出半格可同时指定朝向，目的地是按下的位置，与普通移动使用同一手势。直接右键点击使用计划默认朝向；原地转向则在该队员的计划位置按右键拖动。Esc、地图外松开或切换队员／阶段取消当前拖动。右栏没有专门的位置／朝向按钮；↑/↓ 只调整进入顺序。
- **撤销与退出**：Ctrl+Z 撤销站位、朝向、顺序、道具落点和设置调整。“退出 · 留草稿”或逐层 Esc 后可从地图左上恢复草稿；新关卡会清空本局草稿。恢复时重新检查可用性。
- **提交**：“计划设置”可改入口、突入方式、同步、替换／追加。提交前固定显示影响成员和旧行动；点击“下达计划”后保持暂停，按空格执行。编辑中空格不会启动旧任务。
- **就位警戒**在指定站位留守；**检查威胁**继续巡查观察点。自定义站位受阻会挂起，不静默换位。房间警戒仍先选位置再选朝向。
- 计划编号保持可读；箭头长 1 格。普通右键拖动半格指定移动朝向。“返回原视野／聚焦入口”可切换观察范围。

焦点指挥：普通点击不受房间名称拦截；按住 Ctrl 高亮鼠标所在房间，Ctrl＋右键房间内任意位置在右栏打开房间操作。名称平时不铺底，鼠标靠近时隐藏，按 Ctrl 时显示高亮。

右栏随明确点击的对象切换：无选择显示战局概况，选中队员显示个人／批量操作，房间显示房间行动，物资显示搜索／分配，草稿显示编排与下达。查看对象保留原队员选择作为执行者；Esc 或返回可回到队员指挥。悬停不改变主焦点。“近期事件”和“待分配”入口固定在右栏底部；查看事件后恢复原操作及时间状态。

右栏优先显示任务和挂起原因，无同步行动时隐藏放行区；选中队员可打开“伤势与携带详情”。容器右侧显示候选人的职责、伤势、距离、预计负重和命令影响。

容器操作：双击安排当前交互角色到场拿取；右键改派或撤销单件预约。“仅查看下一处”保留当前等待，“完成此处并处理下一处”依次结束各来源的决定。Esc / “完成此处分配”保留已安排的拿取，其余物品留在来源，关闭后按空格执行。详情窗口可直接从分配侧栏打开，返回不丢失预约。当前仍是场内功能演示，尚无撤离和跨局入库。

四人小队、顶视角、实时推进与自由暂停的 Windows 战术指挥 Demo。1.5.1 改为地图引线容器窗口，双击当前角色拾取、右键选择其他角色。当前关卡用于功能正确性验证。1.5 加入宏观／微操搜物资、暂停分配、现场拿取、携带容量及尸体回收。保留原有 10 名敌人的战斗演示，清除威胁后可继续搜索。

## 直接启动

双击项目根目录的 `Start Demo.cmd`，或打开 `release/v1.7.4/ScarletContract/ScarletContract.exe`。发布包已包含 Python、中文字体和音效，无须安装依赖，也不需要联网。复制给另一台电脑时，请复制整个 `ScarletContract` 文件夹，保留 `_internal`。

先选配置 A，点击“开始行动”→“进入关卡”。开局处于暂停状态，可以先下达计划。

## 第一条命令

**先试搜索：**右键出生位置旁的黄色“现场补给箱”→指定 1 号搜索→空格恢复。读条完成后自动暂停，地图上弹出引线指向箱子的物品窗口。双击弹药由 1 号拿取；右键步枪选择 2 号。已安排物品可右键选择其他人覆盖拿取者，或双击改派给当前交互角色；重复选同一人保持原进度。此时物品仅被预约，枪仍在箱内；关闭窗口、按空格后，2 号走到箱子旁，完成拿取。按 `I` 查看携带物品，可装备该枪或放到脚下。

**再试宏观：**全选已在 S 区的队员→按住 Ctrl，右键南侧安全区内任意位置→“搜索区域物资”→全员搜索，或让最后一人警戒。每次搜出物品都使用同一分配界面。搜索宏观的参与者必须已在目标区域；进入其他房间使用原有门口行动。

未打开的容器／尸体为亮黄，开始翻查后为暗黄；暗黄不代表空。“空”标记表示已知搜空。散落物品保持亮黄，拿空后消失。尸体可跨过，经过时速度为正常地面的 60%；散落物不阻挡、不减速。

**门口行动：**

1. 默认已选全队。右键队员北侧的 S–R 门。
2. 在右栏点“突入”→“直接突入”→“编排站位”。切换阶段，点选队员编辑后，点击“下达计划”；也可选择“立即下令”使用默认站位。
3. 按空格恢复时间。队员集结、开门、依次进入，默认就位警戒；选择“检查威胁”才会继续检查观察点。
4. 右键队员卡可单独查看这个人的物品，原来的全队选择会保留。

闪光突入需要指定落点。橙色范围表示可能震撼友军；闪光不会区分阵营。长走廊与未搜索的侧面需要额外警戒，不能把“已搜索”当作永久安全。

## 指挥权与自主反应

- **重叠减速**：两人重叠时只让其中一人以原速的 45% 继续移动，另一人保持原速，分开后继续减速 0.5 秒再恢复，再次重叠刷新计时；暂停时不计时。较慢者减速，原速相同则固定由编号较大者减速；没有自动停步等待，多人减速不叠乘。途中允许短暂穿行，最终站位不能重叠。
- **八方向移动**：横纵一步成本 1，斜向一步成本 √2，耗时按实际距离计算。允许绕单侧障碍斜穿；只有两侧通路都受阻时禁止斜穿。敌人与宏观行动共用此规则。
- **物资规则**：搜索揭露情报，双击／右键选人只预约，现场动作完成才转移实物。每人最多携带 18 kg；武器保留独立身份与弹匣状态，拾取不自动装备。当前一行消耗品整堆分配、整堆放下。

- **1.4.2：微操优先于自动交战。** 交火中提交移动或转向后立即执行；有效移动期间不自动停步射击、不自动换弹，来弹只提示。到达后恢复自动交战。定点警戒先到位并转向，再允许自动防御。


- **微操接管取消整组关联宏观行动**：例如四人准备突入，移动其中一人会取消这次突入。Shift 不绕过接管规则；预览会提示影响成员。
- **意外挂起计划**：未知方向命中或近失让宏观行动及非移动／转向个人节点挂起；当前有效微操移动／转向继续执行。搜索结束后须在行动面板点击继续；不会自行恢复突入。
- **正常交战继续计划**：已确认敌人的交战属于行动执行；声音只提供区域线索，不能揭示隐藏敌人。
- 普通移动结束保留到达朝向。右键拖拽指定的是固定方向；每个 Shift 路段可指定不同方向。Esc 或地图外松开取消拖拽。

完整规则见 [指挥与 AI 执行规范](docs/command_and_ai.md)。

## 从源码运行

Python 3.12。运行时依赖只有 pygame-ce 2.5.7。

```powershell
cd combat_demo
python -m pip install -r requirements.txt
python main.py
```

`python main.py --config B` 指定初始配置。`python main.py --headless --capture artifacts/start.png` 运行真实渲染器生成开局截图后退出。
